# Methodology

The graph separates jurisdictions and evidence levels. Current-officeholder and institutional nodes are added only with official county sources. Financial, contractual, parcel, lobbying or project-specific relationships must be sourced before promotion from the research framework.

Grades: A financial/contractual; B institutional/professional; C same project/decision; D unverified research lead. Grades describe the relationship evidence, not misconduct.

## Land-record integration
LANDEX use is recorded county-by-county. The project does not infer API availability from web access. Automated access must be supported by documented authorization. Non-LANDEX counties retain their own official Recorder/GIS systems.
